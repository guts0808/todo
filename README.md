# TODO

ビルド不要・依存ライブラリなしのシンプルな TODO アプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます。

```sh
open index.html
# またはローカルサーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

## 機能

- TODO の追加（期限日は任意）
- 完了／未完了の切り替え、すべて完了にする
- 編集（タイトルをダブルクリック、または ✎ ボタン。Enter で確定・Esc でキャンセル。空にすると削除）
- 削除、完了済みの一括削除
- フィルター（すべて／未完了／完了済み）— URL ハッシュ（`#/active` など）と連動
- 期限が今日・期限切れのものを色で強調
- `localStorage` に自動保存（複数タブ間でも同期）
- ダークモード対応、スマホ幅対応

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面のマークアップ |
| `style.css` | スタイル（ライト／ダーク） |
| `app.js` | 状態管理・描画・イベント処理 |
